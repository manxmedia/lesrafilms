LESRA FILMS — WINDOWS SETUP

The previous ZIP was incomplete: it did not contain package.json or the app/ directory.
That is why npm returned ENOENT.

1. Extract this ZIP.
2. Open PowerShell in the folder that CONTAINS package.json.

You should be able to run:
    dir package.json

It must show package.json.

3. Install dependencies:
    npm install

4. Start the development server:
    npm run dev

5. Open:
    http://localhost:3000

6. For a production test:
    npm run build

IMPORTANT:
If your extracted path is:
C:\WEB PROJECTS\www.lesrafilms.co.zw\www.lesrafilms.co.zw

then run:
    cd "C:\WEB PROJECTS\www.lesrafilms.co.zw\www.lesrafilms.co.zw"

and then:
    npm install

Do NOT run npm install from a folder that does not contain package.json.
